# SilenceFun — White noise synthesis demos

[中文版本 / Chinese version](README.zh-CN.md)

A curated set of **white noise synthesis demos** extracted from [SilenceFun](https://silencefun.com/en/) — each one is a single self-contained file with no build step and no tracking scripts.
